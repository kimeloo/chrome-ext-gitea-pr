# Gitea PR Status

나와 관련된 Gitea Pull Request 현황을 크롬 툴바 팝업으로 한눈에 보여주는 확장 프로그램입니다.

## 주요 기능

- **다섯 가지 탭**: 리뷰 요청 · 내 PR · 담당 · 리뷰함 · 멘션. 탭 순서는 설정에서 끌어서 바꿀 수 있습니다.
- **PR 정보 한눈에**: 저장소, 브랜치, 작성자, 리뷰어, 리뷰 상태, CI 상태, 병합 가능 여부, 라벨, 마일스톤, 변경 규모, 마감일 등. 필요 없는 항목은 설정에서 끌 수 있고, 저장 전에 미리보기로 확인할 수 있습니다.
- **브라우저 알림(선택)**: 새 PR, 리뷰어·담당자 지정, 코멘트, 리뷰, 새 커밋, 머지, CI 결과 등을 1~60분 주기로 확인해 알려줍니다. 기본값은 꺼짐입니다.
- **테마**: 시스템 설정 / 라이트 / 다크

## 설치

### 릴리즈 파일로 설치 (권장)

1. [Releases](https://github.com/kimeloo/chrome-ext-gitea-pr/releases)에서 최신 `gitea-pr-extension.zip`을 내려받아 압축을 풉니다.
2. 크롬 주소창에 `chrome://extensions`를 입력해 확장 프로그램 관리 페이지를 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 압축을 푼 폴더를 선택합니다.

### 소스 코드로 설치

1. 이 저장소를 내려받습니다.
2. 크롬에서 `chrome://extensions`를 열고 오른쪽 위 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 저장소의 `extension` 폴더를 선택합니다.
설치가 끝나면 설정 페이지가 자동으로 열립니다. 툴바의 퍼즐 아이콘에서 **Gitea PR Status**를 고정하면 아이콘이 항상 표시됩니다.

## 설정

1. Gitea에서 **프로필 → 설정 → 애플리케이션 → 새 토큰 생성**으로 토큰을 만듭니다.
   권한은 `issue`, `notification`, `repository`, `user`를 **읽기**로 선택합니다. (`notification`은 브라우저 알림을 쓸 때만 필요합니다.)
2. 확장 프로그램 설정 페이지에 Gitea 주소와 토큰을 입력하고 **저장**을 누릅니다.
   하위 경로에 설치된 Gitea라면 경로까지 입력합니다. 예: `https://example.com/gitea`
3. 크롬이 사이트 접근 권한을 물으면 **허용**합니다. `✓ {계정} 계정으로 연결되었습니다.`가 표시되면 완료입니다.

알림이 보이지 않으면 운영체제의 알림 설정에서 Chrome 알림이 켜져 있는지 확인하세요.

## 개인정보

- 토큰과 설정은 이 브라우저 안에만 저장되며 크롬 동기화로 전송되지 않습니다.
- 요청은 직접 입력한 Gitea 서버로만 전송됩니다. 별도 서버, 분석 도구, 광고, 외부 CDN을 사용하지 않습니다.

자세한 내용은 [개인정보처리방침](PRIVACY.md)을 참고하세요.

## 지원 환경

Gitea 1.22 이상을 기준으로 합니다. 이전 버전에서는 일부 항목(초안, 변경 규모 등)이 자동으로 숨겨집니다.
