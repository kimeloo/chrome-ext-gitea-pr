Gitea 연결

하위 경로에 설치된 경우 경로까지 입력합니다. 예: https://example.com/gitea

토큰은 이 브라우저의 확장 저장소(chrome.storage.local)에만 저장되며 동기화되지 않고, 입력한 Gitea 주소로만 전송됩니다.

  1. Gitea → 오른쪽 위 프로필 → 설정 → 애플리케이션
  2. 새 토큰 생성: 권한에서 issue · notification · repository · user 를 '읽기'로 선택
  3. 생성된 토큰을 붙여넣고 저장

테마

알림

Gitea 알림함 기준입니다. watching 중인 저장소와 내가 참여한 PR의 소식을 받으며, 저장소 watch 설정은 Gitea에서 바꿀 수 있습니다.

Gitea 웹에서 이미 읽은 알림과 내가 한 행동은 알리지 않습니다.

알림이 보이지 않으면 운영체제의 알림 설정에서 Chrome 알림이 켜져 있는지 확인하세요.
